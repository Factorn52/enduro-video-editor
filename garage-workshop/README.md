# Гараж 6×3 — сдвоенный верстак со сливом + стеновые панели из фанеры

Комплект для производства:
- чертежи — PDF, 11 листов A3;
- DXF для лазера и для ЧПУ;
- спецификация и смета;
- заявка для цеха;
- отчёт автопроверки (144 пункта);
- протокол независимой экспертизы.

## Что получилось

**Верстак 2800 × 700, высота 950** (под рост 187 см). Стоит вдоль узкой (задней) стены 3 м, по 100 мм до боковых стен. Состоит из двух модулей 1400 × 700: они стягиваются болтами М8 через ноги (с квадратными шайбами) и крепятся к стене ушами с анкерами.

| Модуль | Назначение | Устройство |
|---|---|---|
| **А — слив** (слева) | разборка вилок и моторов, мойка деталей | Поддон из нержавейки AISI 304 1,5 мм. Дно с уклоном ~2 % к **переднему левому** углу. Слив: колпак-фильтр → полумуфта G1/2" насквозь → кран у фронта → шланг → канистра 20 л на полке-поддоне (AISI 430, борт 40, ≈38 л). Сверху 4 съёмные решётки 3 мм вровень со столешницей Б. Внутренние борта решёток уходят на 30 мм ниже полки поддона — это жёсткость и фиксация. Без решёток — ванна; рабочий уровень до риски 40 мм (≈16 л). |
| **Б — рабочий** (справа) | слесарка, тиски, правка | Фанера 18 мм на 3 поперечинах + крышка из нержавейки 1,5 мм; сзади бортик 19,5 мм вверх. **Плита 20 мм 450×300** в левом переднем углу — вровень со столешницей, над стянутыми ногами стыка: справа на плите тиски, слева зона правки. Под столешницей ниша под тумбу (h ≤ 870). |

**Стеновые панели:** 2 шт. 1400 × 1200 из фанеры 18 мм. Сетка ø8 с шагом 50, панели на вертикальных рейках (крепёж симметричный).

**Держатели:** отвёрточница, ключница, полка для химии, ложементы под перо вилки. Каждый держатель стоит на 4 шкантах и 1 саморезе.

**Вся фанера** раскраивается из 2 листов 2440 × 1220.

## Кому что отдать

| Куда | Что |
|---|---|
| **Лазер + гибка** | `DXF_laser/L*.dxf` (материал, толщина и количество — в имени файла) + листы 4–7 PDF + `Заявка_лазер_гибка.txt`. Слои: CUT — рез; BEND_UP / BEND_DOWN — оси гибов; DRILL — сверлить. Оснастку для поддона Л2 согласовать **до** резки. |
| **ЧПУ-фрезер (фанера)** | `DXF_cnc_fanera/NEST_fanera_list1…2.dxf` |
| **Резка труб и сварка** | Листы 2, 3 (каркасы, порядок сборки), 6 (плита и втулки), 8 (карта резки), 4 (поддон — TIG) |
| **Закупка** | `Спецификация.csv`, лист 8, `Смета.md` (цены и где заказать) |

## Обязательно перед заказом

1. **Замерить гараж** у задней стены. Если ширина меньше 2900 — поменять `MOD_W` в `src/geom.py` и пересобрать.
2. **Гибщик** подтверждает K-фактор и радиус (у нас K = 0,42, Rвн = t), а для поддона — оснастку и базирование (таблица на листе 4).
3. Плита должна выступать над крышкой на 0,5–1,5 мм: замерить фактические толщины, при необходимости подложить подкладки.
4. В ванне — только дизтопливо, керосин или водные очистители, **не бензин**. Фен и болгарку — над модулем Б.

## Рекомендации (в проект не вошли, по желанию)

- Розеточный блок IP44 над модулем Б на высоте 1100–1150 (над модулем А — ничего электрического).
- LED-светильник по верху панелей.
- Держатель бумажных полотенец, магнитная планка под головки.
- Крюки под динамометрические ключи.
- Стойка-сушилка для перьев вилки над модулем А.
- Сплошная крышка для ванны (лист 430 толщиной 1 мм).
- Ложемент для мотора по месту.

## Документы

- `Экспертиза_и_решения.md` — 58 замечаний четырёх экспертов и решение по каждому.
- `Проверка_размеров.txt` — отчёт автопроверки (`src/check.py`): контуры развёрток, DXF, 3D-стыковки с косынками и крепежом, опирание фанеры, объёмы ванны и канистры, комплектность раскладок.
- `Смета.md` — ориентировочная стоимость листовых деталей и где заказать.

## Пересборка

```bash
pip install ezdxf shapely matplotlib
python3 src/build.py            # DXF → проверка → смета → CSV → PDF
```

Все размеры задаются в `src/geom.py`.
